# Проверка RETROTUNE

## Обновление 0.2.0 — 6 ноября 2026

- TypeScript и production-сборка проходят; восемь тестов API/Python проходят, включая совместимость старых пресетов и проверку `language`.
- Английский язык проверен во всех трёх панелях редактора, в инструкции, подписях и статусах; при демонстрационных данных кириллического текста в английских панелях нет. Реальные названия/исполнители намеренно не переводятся.
- Проверены RU → EN → RU, сохранение языка на сервере и восстановление после перезагрузки. Тёмная тема редактора сохраняется в localStorage и не меняет палитру эфирного виджета.
- EN / dark проверены на 1440, 768 и 390 px: общего горизонтального переполнения нет. Скриншоты `docs/images/` используют демотрек и скрытый список личных источников.
- Повторный smoke расширения 0.2 подтвердил обе локализации popup и передачу названия, исполнителя, PNG-обложки, длительности, паузы и отключения.
- Полная проверка совместимости всех музыкальных сервисов, чистой установки на другом ПК и ручной аудит screen reader по-прежнему не заявляются. Lua-язык добавлен в свойства; загрузка Lua в текущую пользовательскую конфигурацию OBS не выполнялась.

Ниже сохранён исходный протокол 0.1; новые результаты расширяют его, не закрывая перечисленные ограничения автоматически.

Дата: 6 ноября 2026. Windows, Python 3.12.10, Node 24.14.0, OBS Studio 33.0.1.

## Выполнено

- Production-сборка `npm run build`: TypeScript без ошибок, Vite собирает интерфейс. Локальный шрифт Tiny5 включён в поставку.
- Семь автоматических тестов Python/aiohttp: валидация цветов/размеров/флагов, запрет некорректных URL и бесконечных значений, границы Host и токена, отсутствие CORS, повреждённый/слишком большой запрос, сохранение на диск, восстановление и сохранение предыдущих настроек при ошибке, переключение/просрочка/удаление внешних источников, отсутствие подмены закреплённого источника.
- Playwright, реальный сервис: демо только в редакторе; пять компоновок; включение диска; остановка анимации на паузе; перестановка блоков; длинное русское название и бегущая строка; заглушка без обложки; интерполяция прогресса; скрытие на паузе; отсутствие другого трека после исчезновения закреплённого источника; прозрачность body **и html**; окно инструкции и Escape.
- Интерфейс проверен на ширинах 1440, 768 и 390 px. Общего горизонтального переполнения нет; широкий виджет автоматически вписывается в предпросмотр. Скриншоты: `output/playwright/editor-*.png`.
- Windows GSMTC: сервис подключается и получает реальную сессию Brave, название и состояние паузы. Во время проверки отдельного профиля браузера также обнаруживалась 20-секундная HTMLAudio-сессия с тестовыми метаданными.
- Расширение загружено в отдельный профиль установленного Brave, не в пользовательский профиль. Цепочка page MAIN → relay ISOLATED → service worker → локальный API прошла: русское название, исполнитель, альбом, PNG-обложка из MediaSession, длительность 20 s, playing, пауза и отключение вкладки. Для проверки connect использовано сообщение из страницы расширения с ID тестовой локальной вкладки. Ручное нажатие значка расширения на стороннем музыкальном сайте не проверялось.
- OBS: создан источник `RETROTUNE — музыка` (Browser Source, 1280×720) в отдельной сцене `RETROTUNE — виджет`. Прозрачный источник реально отрисован в студийном Preview и снят через obs-websocket. Видны русское название, статус, CD, заглушка обложки, прогресс и время. PNG имеет RGBA, пиксель вне виджета — `(0,0,0,0)`. Программная сцена и состояние выходов сохранены; студийный режим и Preview восстановлены. Нативный снимок: `output/playwright/obs-native.png`.
- Скрипты Start/Stop фактически перезапускали фоновый сервис, после чего API и браузерный smoke снова работали.

## Оставшиеся границы проверки

- Lua-файл поставляется как способ автозапуска и добавления источника; его загрузка через окно «Скрипты» в текущую конфигурацию OBS не выполнялась. Источник проверен напрямую через OBS Browser Source/obs-websocket.
- Не проверены все музыкальные сервисы, сторонние приложения, отдельные версии Chrome/Edge, защищённые плееры, iframe, закрытый Shadow DOM и браузеры вне Chromium. В обычном пользовательском профиле расширение не установлено.
- Передача обложки проверена через расширение и общий renderer; чтение реальной обложки из Windows Thumbnail не было отдельно подтверждено на музыкальном плеере с обложкой.
- Нет проверки на другом компьютере/чистой Windows, непрерывного многочасового прогона, ручного аудита screen reader и всех сочетаний клавиатуры/контраста пользовательских тем. Виджет сам не воспроизводит аудио; аудиомикс не проверялся и не менялся.
- Данные зависят от метаданных плеера. Неизвестная длительность не подменяется вымышленной; отсутствующие поля имеют заглушки.

Архив поставки включает исходники, собранный интерфейс, расширение, Lua, запуск и инструкции; исключает `.venv`, `node_modules`, локальные ключи/настройки, журналы, профили тестовых браузеров и временные материалы проверки.
