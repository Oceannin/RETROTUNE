# RETROTUNE

Локальный музыкальный виджет для OBS под Windows 10/11. Визуальный стиль — серебристое ретроокно с синим заголовком, пиксельным шрифтом и CD-диском, по предоставленному референсу.

Интеграция состоит из источника OBS «Браузер», локального редактора и Lua-скрипта. Нативная DLL не требуется. Звук виджет не захватывает: в OBS отдельно добавляется «Захват выходного аудиопотока приложения» или другой аудиоисточник.

## Запуск

После установки через **Setup RETROTUNE.cmd** откройте **Start RETROTUNE.cmd**. Редактор: [http://127.0.0.1:47832](http://127.0.0.1:47832).

Ярлык **RETROTUNE** с собственной ретроиконкой создаёт `Create-Desktop-Shortcut.ps1`. Он запускает сервис скрыто и открывает редактор. После переноса проекта повторно создайте ярлык из новой папки. Иконка ICO с восемью размерами находится в `public/assets/retrotune.ico`; оригинал PNG и описание дизайна сохранены в проекте.

Если источник уже создан, его можно переиспользовать в другой сцене через «Браузер → Добавить существующий».

Для остановки сервиса — **Stop RETROTUNE.cmd**. Сервис работает скрыто в фоне, пока запущен процесс Python. Закрытие вкладки редактора его не завершает. Автозапуск Windows не устанавливается.

## Подключение к OBS

1. Запустите сервис.
2. OBS → «Сервис → Скрипты → +»: выберите `obs/retrotune.lua` из этой папки. При загрузке скрипт запускает сервис. «Открыть редактор» открывает настройки; «Добавить виджет в текущую сцену» создаёт или переиспользует источник.
3. Вручную: добавьте «Браузер», отключите «Локальный файл», URL `http://127.0.0.1:47832/overlay`, размер **1280 × 720**, частота 60 fps. Ширина самого виджета задаётся в редакторе; свободное место источника прозрачно. Чтобы убрать свободное место при позиционировании, обрежьте источник с Alt или фильтром обрезки OBS.
4. Редактор внутри OBS: «Док-панели → Пользовательские док-панели браузера», имя RETROTUNE, URL `http://127.0.0.1:47832`.

Не перемещайте один Lua-файл отдельно от проекта: он ищет запускающий скрипт в родительской папке.

## Источники

**Windows.** Сервис читает GlobalSystemMediaTransportControlsSessionManager. Поддерживаются приложения, публикующие системную медиасессию: название, исполнитель, обложка, длительность и позиция доступны в той мере, в какой их отдаёт плеер. Все доступные сессии появляются во вкладке «Источники». Автовыбор берёт первый воспроизводящийся источник; при отсутствии воспроизведения — первый доступный. Можно закрепить один источник. Если он исчез, другой трек автоматически не подставляется.

У нескольких сессий одного приложения Windows идентификатор содержит порядковый номер; порядок может измениться при закрытии сессий. Для точного закрепления вкладки используйте расширение. После перезапуска плеера проверьте выбранный источник.

**Конкретная вкладка.** Расширение Manifest V3 для Chromium, Chrome, Edge и Brave:

1. Откройте страницу расширений вашего браузера (`chrome://extensions`, `edge://extensions` или `brave://extensions`), включите режим разработчика и «Загрузить распакованное» → папка `browser-extension`.
2. В редакторе RETROTUNE → «Источники» → «Копировать ключ подключения».
3. Перейдите на страницу с музыкой, откройте расширение, вставьте ключ и нажмите «Подключить эту вкладку».
4. Закрепите появившуюся вкладку в редакторе. Расширение передаёт только подключённые вкладки. Несколько вкладок можно подключить одновременно.

После перезагрузки или перехода страницы подключите её заново. Разрешения: activeTab, scripting, storage и доступ к локальному сервису. Постоянный доступ ко всем сайтам не запрашивается. Обычные HTML `<audio>/<video>` дают позицию и длительность, MediaSession даёт название, исполнителя и HTTPS-обложку. Встроенные iframe, WebAudio без доступного HTMLMediaElement, закрытый Shadow DOM и некоторые защищённые плееры не поддерживают полный набор данных. Если прогресс недоступен, вымышленная длительность не создаётся. Firefox в этой версии не поддерживается.

**Другие приложения.** Только по аудиосигналу получить достоверную обложку и название невозможно. Для плеера без системной медиасессии потребуется адаптер к его API/плагину. Локальный JSON API реализован ниже. Автоматическое распознавание музыки не включено.

## Оформление

Верхняя панель редактора содержит переключатели **RU / EN** и **светлой / тёмной темы**. Язык хранится в настройках сервиса и применяется к подписям оверлея; тема редактора сохраняется в localStorage отдельно от оформления виджета в эфире. При первом запуске тема следует системному предпочтению. Расширение получает язык от локального сервиса; его цветовая схема следует системной. Lua-помощник имеет свой переключатель языка EN/RU.

- Классика, CD-плеер, минимализм, вертикальная и пользовательская компоновки.
- Обложка, диск, название, исполнитель, статус, прогресс, время и заголовок окна включаются отдельно.
- Блоки «обложка + диск» и «информация» можно менять местами. В вертикальной компоновке порядок идёт сверху вниз. Свободного перетаскивания по холсту в этой версии нет.
- Четыре темы, шесть независимых цветов, размеры, отступы, скругления, прозрачность и размер шрифта.
- Длинные названия и исполнители прокручиваются только при переполнении. При отключении строки используется многоточие, полный текст доступен во всплывающей подсказке. Системная настройка reduced motion отключает анимации.
- Диск вращается во время воспроизведения. Нет обложки — показывается аккуратная заглушка. Можно скрывать виджет на паузе или без источника.
- Демо-трек отображается только в редакторе. Настройки меняют эфирный виджет сразу и сохраняются автоматически в `data/settings.json`. Импорт/экспорт пресета — JSON.
- При очень узком виджете размер обложки и расстояние между блоками автоматически ограничиваются, чтобы осталось место тексту. Предпросмотр автоматически вписывается в доступную область; ползунок задаёт верхний предел масштаба.

## Локальный API для адаптеров

Адрес `http://127.0.0.1:47832`, доступ только через loopback. Все записи требуют заголовок `X-Retrotune-Token`; ключ находится в `data/token.txt` или копируется в редакторе. Не добавляйте ключ в URL оверлея. Данные и ключ не включены в архив поставки.

`POST /api/ingest`, Content-Type: application/json:

```json
{
  "id": "my-player:main",
  "label": "Мой плеер",
  "title": "Название трека",
  "artist": "Исполнитель",
  "album": "Альбом",
  "cover": "https://example.com/cover.jpg",
  "position": 42.5,
  "duration": 224,
  "rate": 1,
  "playing": true
}
```

Отправляйте текущее состояние раз в 1–3 секунды и сразу после паузы/перемотки/смены трека. Источник исчезает через **12 секунд** без обновлений. Позиция и длительность — секунды, скорость от 0 до 16; для неизвестной длительности используйте 0. `sampledAt` задаёт сервер при получении; во время воспроизведения клиент интерполирует прогресс. Обложка — HTTPS либо data URL PNG/JPEG/WebP, без SVG; общий запрос ограничен 3 MB. ID `auto`, `demo` и префикс `windows:` зарезервированы. До 64 внешних источников одновременно.

`POST /api/remove-source`: `{"id":"my-player:main"}`. `GET /api/state` — текущие настройки и выбранный трек, `GET /api/bootstrap` — также список сессий, состояние Windows и локальный ключ. `PUT /api/settings` — валидируемый объект настроек; неуказанные поля принимают значения по умолчанию, поэтому адаптеру следует сначала прочитать текущие настройки. Вредоносные сайты не получают CORS-доступ; Host ограничен localhost/127.0.0.1:47832. Это локальный инструмент, не публичный веб-сервис; не проксируйте его в Интернет.

## Установка на другом компьютере и разработка

Windows 10 1809+ / Windows 11, Python 3.12 x64 (проверено), Node.js 20.19+ или 22.12+. Запустите **Setup RETROTUNE.cmd**, затем **Start RETROTUNE.cmd**. Установщик использует lockfile npm и версии Python из `requirements.txt`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
npm run build
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-RETROTUNE.ps1
```

Для разработки запустите сервис и `npm run dev`; Vite проксирует `/api` в локальный сервис. Production-сборку обслуживает Python без зависимости от Node.js при каждом запуске. UI — React/TypeScript, backend — Python/aiohttp/PyWinRT. `src/Widget.tsx` общий для предпросмотра и OBS; `src/model.ts` — контракт состояния; `server.py` — сбор сессий, хранение и API.

Проверки:

```powershell
npm run build
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
npx --yes --package @playwright/cli playwright-cli -s=retrotune open http://127.0.0.1:47832
npx --yes --package @playwright/cli playwright-cli -s=retrotune run-code --filename=tests/browser-smoke.cjs
```

Локальный конфиг теста расширения создаёт `tools/extension_test_config.py --browser "путь-к-браузеру.exe"`; он сохраняется в `output/extension-config.json` и не публикуется. `tests/obs-smoke.py` использует уже включённый obs-websocket, создаёт отдельную сцену/источник, временно показывает тестовый источник в студийном Preview и восстанавливает настройки и Preview. Программная сцена и состояние записи/трансляции проверяются до/после. Скрипт не включает obs-websocket и не меняет его настройки.

Итоги и ограничения проверки — `VERIFICATION.md`.

## Если не работает

- Нет связи с редактором: запустите Start; проверьте `data/server-error.log`. Порт 47832 должен быть свободен.
- Нет источника: включите музыку и откройте системную панель мультимедиа Windows. Если плеер там не представлен, используйте расширение или адаптер.
- Пустой виджет: проверьте выбранный источник, «Скрывать на паузе» и поведение при недоступном источнике. Демо не отправляется в OBS.
- Нет картинки/прогресса: конкретный сервис может не предоставлять эти поля или запрещать загрузку обложек вне сайта. Данные не придумываются.
- Lua не запускает сервис: используйте Start вручную; проверьте, что структура папок сохранена. Не копируйте только Lua-файл.
- Переустановка: сохраните `data/settings.json` для восстановления оформления. Ключ локального расширения лежит в `data/token.txt`.
