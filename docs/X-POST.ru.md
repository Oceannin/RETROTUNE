# Пост для X

Сделал RETROTUNE для OBS — музыка на стриме в стиле Windows 95.

Обложки, крутящийся CD, бегущая строка и прогресс. Музыка из плеера или вкладки браузера. Тёмная/светлая тема, RU/EN, локальная работа.

Код и превью: https://github.com/Oceannin/RETROTUNE
